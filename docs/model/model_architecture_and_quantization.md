# Narrative-Nano モデルアーキテクチャ & 量子化仕様

## 1. モデル設計思想
- **目的**: 汎用テキスト生成ではなく、「文芸テキストからの動的キャラクター状態追跡」「格関係抽出」「世界観矛盾検知」に特化した極小判定モデル。
- **アーキテクチャ**:
  - パラメータ数: 数百万〜1,000万パラメータ未満
  - コンテキスト長: 256〜512 トークン（段落・文単位のスライディングウィンドウ）
  - 語彙サイズ: 文芸特化の縮退語彙（約 4,000〜8,000 トークン）
- **量子化**:
  - 8-bit Integer (INT8) 量子化によるメモリ節約と SIMD 整数積和演算の最大活用。
  - 重みサイズ: 約 2〜4 MB
