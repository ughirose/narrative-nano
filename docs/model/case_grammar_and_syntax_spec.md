# 日本語格文法・係り受け解析仕様 (10格粒子)

## 1. 定義対象の10格助詞
Narrative-Nano では、文芸文における主語・客体・移動・場所・時間を正確に識別するため、以下の 10 種の格関係を追跡する。

1. **主格（ガ）**: 行為の主体、状態の主語
2. **対格（ヲ）**: 直接目的語、移動の通過点
3. **与格/着格（ニ）**: 相手、到達点、存在場所、帰着時間
4. **具格/於格（デ）**: 手段、道具、行為の行われる場所
5. **共格（ト）**: 共同行為者、引用、変化の結果
6. **奪格（ヨリ）**: 起点、比較の基準
7. **起点格（カラ）**: 時間・空間の出発点、原因
8. **終点格（マデ）**: 時間・空間の到達限界
9. **方向格（ヘ）**: 移動の向かう方向
10. **連体修飾格（ノ）**: 所有、所属、属性の限定

## 2. 状態遷移追跡アルゴリズム
文中で「AがBを倒した」「CがDへ移動した」等のイベントが検出された際、オントロジーデータベース内の各エンティティの SCD Type 2 履歴テーブルに新たなスナップショットを生成する。
