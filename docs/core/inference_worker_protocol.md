# 推論 Worker 通信プロトコル & リアルタイム評価仕様

## 1. 概要
UI スレッドの入力に対して 60fps を維持したまま、打鍵ごとにバックグラウンドで動作する NanoEvaluator Worker の通信プロトコル。

## 2. 実行シーケンス
1. CodeMirror 6 から確定された文字列差分が SPSC Ring Buffer に書き込まれる。
2. Worker 側で Ring Buffer からパケット（320B）をポップ。
3. トークン化および C++ Wasm SIMD コアへのポインタ渡し。
4. サブミリ秒（< 0.05ms）でのフォワードパス実行。
5. 係り受け・格関係・エンティティ状態遷移を解析し、矛盾が検知された場合のみ UI スレッドへ通知（Linter デコレーション反映）。
