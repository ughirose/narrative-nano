# 20260924_【技術資料】物語テキストにおける動的キャラクター状態追跡とイベント抽出の計算論的展開

## 物語テキストにおける動的キャラクター状態追跡とイベント抽出の計算論的展開
自然言語処理および計算言語学において、物語テキスト（Narrative Text）からの動的キャラクター状態追跡（Dynamic Character State Tracking）とイベント抽出（Event Extraction）は、談話理解（Discourse Understanding）と常識推論（Commonsense Reasoning）が交差する最重要課題の一つである。物語文脈は静的な知識グラフと異なり、時間的進行に伴って登場人物の物理的位置、身体的状態、所有関係、ならびに複雑な対人関係が不可逆的あるいは条件付きで変容する。本報告では、機械読解、記号的推論、ニューラル言語モデルの統合的観点から、状態追跡ベンチマークの進化、数理・オントロジー的定式化、イベント文の弁別手法、および日本語特有の言語現象に対する実装エコシステムを包括的に論じる。
### 1. 動的状態追跡（Character State Tracking）の変遷と評価ベンチマーク
物語テキストから登場人物の状態変化を追跡する研究は、当初の明示的な固有表現抽出や単純な共参照解決の枠組みから、文脈中に明記されない暗黙的状態の推論へと深化を遂げてきた。Li et al. (2021)「Tracking Character States in Stories」は、談話の進行に伴い暗黙的に変容するキャラクターの物理的・心理的属性をエンティティ単位で継続的に更新・追跡する問題設定を確立し、後続の研究に大きな影響を与えた。
#### 1.1 主要ベンチマークとデータセットの進化
Li et al. (2021) 以降のベンチマーク群は、単なる表層的な属性予測を超え、推論プロセスの検証可能性（Verifiability）、長編生成における時間的・論理的一貫性（Narrative Consistency）、および反事実的推論（Counterfactual Reasoning）を厳密に測定する方向へと拡張されている。
- TRIP (Tiered Reasoning for Intuitive Physics): 物理的常識推論の論理的連鎖を多層的に評価するベンチマークである。物語の妥当性判定という高次タスクに加え、その論理的根拠となる文ペアの特定、および各アクションの「事前条件」と「事後効果」の正確な追跡が要求される。表層的な相関関係に依存したモデルの脆弱性を排し、物理状態の遷移プロセスをモデルが真に追跡できているかを検証可能にしている。
- PASTA (Participant States Dataset): 明示的に記述されない登場人物の暗黙的状態（所持、身体状態など）を追跡するデータセットである。文脈から参加者の状態を同定する「状態推論（Story State Inference）」、反事実的な状態が与えられた際に物語全体を最小限の修正で書き換える「反事実的物語改変（Story Revision for Counterfactual States）」、ならびに修正前後の物語対から生起した差分状態を抽出する「状態変化生成（State Change Generation）」の3タスクを提示し、因果関係の双方向推論を評価する。
- ConStory-Bench: 近年の大規模言語モデル（LLM）による超長文物語生成において生じる一貫性の破綻を体系的に検出・評価するベンチマークである。登場人物の設定矛盾、獲得した知識の衝突、能力の忘却、時間軸の逆転といった不整合を19のサブタイプに分類し、自己回帰型モデルの長期記憶保持能力と状態追跡の限界を定量化している。
- DialStory: 小説文脈における大規模対話データセット（約10.5万件）であり、プロットの展開と連動したキャラクターの感情変化、動機、および関係性のダイナミクスを反映した発話生成および話者認識の精度を測定する。
- ViStoryBench: 物語から連続的な絵コンテ・画像を生成するマルチモーダルベンチマークであり、テキスト記述と画像系列の間でキャラクターの属性、衣装、空間配置の動的一貫性を追跡・評価する枠組みを提供する。
| ベンチマーク / データセット | 主たる追跡対象 | タスク形式 | 評価の主眼 |
| --- | --- | --- | --- |
| Li et al. (2021) | キャラクターの物理的・心理的状態 | 多肢選択 / スパン抽出 | 談話進行に伴う暗黙的状態変化の更新能力 |
| TRIP (2021) [cite: 1] | 物理的状態（位置、形状、温度等） | 段階的分類（Plausibility + 矛盾特定） | 事前条件・事後効果の因果的連鎖の整合性 |
| PASTA (2022) [cite: 2, 3] | 参加者状態（所持、健康、関係性等） | 状態推論 / 反事実的物語改変 / 状態変化生成 | 暗黙状態の把握と反事実条件下での柔軟な推論 |
| DialStory (2022) [cite: 5] | 登場人物の感情、動機、対人関係 | 話者同定 / 発話生成 | プロット進行と連動した対話・人物像の動的一貫性 |
| ConStory-Bench (2025) [cite: 4] | 人物設定、知識、所持、時間軸 | 自動エラー検出（Characterization, Timeline等） | 超長文生成におけるキャラクター設定の破綻検知 |
| ViStoryBench (2025) [cite: 6, 7] | 人物の外見、動作、空間配置 | 連続画像生成・属性整合性判定 | マルチモーダル環境での時空間的一貫性維持 |

#### 1.2 モデルアーキテクチャの技術的パラダイムシフト
初期のニューラル状態追跡モデルは、EntNet（Entity Networks）やProLocalに代表されるように、エンティティごとに固定次元のメモリスロットを割り当て、入力文ごとに再帰型セルやゲーティング機構によって潜在状態を更新するアーキテクチャを採用していた。しかし、これらのモデルは語彙の共起関係に過適合しやすく、複数段落にまたがる長距離依存や複雑な物理法則を保持することが困難であった。
その後、事前学習済みトランスフォーマーの台頭に伴い、テキスト全体を双方向アテンションで表現しつつエンティティ言及スパンを集約する手法へと移行した。さらに、文脈中で明示されない意図や結果を補うため、ATOMICやCOMETなどの常識知識グラフから「動機（xIntent）」「効果（xEffect）」「心理反応（xReact）」を動的に推論し、生成モデルへ注入するCAST（Commonsense-inference Augmented neural StoryTelling）のようなハイブリッドパイプラインが定着した。
近年の最先端手法では、LLMのインコンテキスト学習能力を基盤としつつ、外部メモリとして動的セマンティック・ナレッジグラフ（Dynamic Semantic Knowledge Graph）を運用する「物語世界モデル（Narrative World Models）」へとアーキテクチャが再編されている。例えばPocket FMのSherpaシステムにみられるように、テキストが進行するたびに登場人物の既知事実、秘密の共有、関係性の変化をグラフデータベースへ構造化して記録し、高精度なリトリーバル機構と連携させることで、数百エピソードに及ぶ長編ストーリーにおいても一貫性の減衰（Continuity Decay）をゼロに抑える設計が実用化されている。
### 2. 状態変化の数理・オントロジーモデルと記号AIハイブリッド
物語におけるアクションや出来事は、物理的・社会的環境をある離散状態から別の状態へと遷移させるオペレータとして厳密に数理モデル化できる。古典的記号AIにおける古典的ストリップス（STRIPS）および計画言語（PDDL: Planning Domain Definition Language）の理論は、近年のニューラルNLPと融合し、制約付き推論やプロット生成の論理的骨格として再評価されている。
#### 2.1 状態とアクションの形式的定義
物語世界の推論系は、離散事象システムとして定式化される。物語世界の状態 $S_t$ は、述語論理のファクト（Fact）の有限集合として定義される。
$$S_t = \{ p_1, p_2, \dots, p_k \} \subseteq \mathcal{P}$$
ここで $\mathcal{P}$ は物語世界で成立しうるすべての論理的命題（アトミックな述語）の空間である。アクション（イベント） $a \in \mathcal{A}$ は、以下の3つ組として定式化される。
$$a = \langle \mathrm{Pre}(a), \mathrm{Eff}^+(a), \mathrm{Eff}^-(a) \rangle$$
$\mathrm{Pre}(a) \subseteq \mathcal{P}$ はアクション $a$ が生起するために直前の状態で成立していなければならない「事前条件（Preconditions）」を表す。$\mathrm{Eff}^+(a) \subseteq \mathcal{P}$ はアクションの実行によって新たに真となる「加算効果（Add Effects）」、$\mathrm{Eff}^-(a) \subseteq \mathcal{P}$ はアクションの実行によって偽となる「削除効果（Delete Effects）」を表す。
状態遷移関数 $\tau: \mathcal{S} \times \mathcal{A} \to \mathcal{S}$ は、事前条件が現在の状態に包含されている場合（$\mathrm{Pre}(a) \subseteq S_t$）にのみ適用可能となり、事後状態 $S_{t+1}$ は差分（State Deltas $\Delta S = \mathrm{Eff}(a)$）を用いて次のように決定論的に導出される。
$$S_{t+1} = (S_t \setminus \mathrm{Eff}^-(a)) \cup \mathrm{Eff}^+(a)$$
もし $\mathrm{Pre}(a) \not\subseteq S_t$ である場合、その物語記述には因果的破綻（Causal Inconsistency）が存在することを意味し、TRIPやConStory-Benchはこの論理的逸脱を検出するタスクとして位置づけられる。
#### 2.2 物語世界のオントロジー分類
物語理解において追跡される主要な状態述語は、物理的ドメイン、社会的・対人関係ドメイン、および認知的・認識論的ドメインに大別される。
| ドメイン | 状態カテゴリ | 述語表現例 | 典型的な事前条件 Pre(a) | 典型的な事後効果 Eff(a) |
| --- | --- | --- | --- | --- |
| 物理的状態 | 位置 (Location) | $\mathrm{At}(c, l)$  $\mathrm{Connected}(l_1, l_2)$ | $a = \mathrm{Move}(c, l_1, l_2)$  $\mathrm{At}(c, l_1) \land \mathrm{Connected}(l_1, l_2)$ | $\mathrm{Eff}^-: \{\mathrm{At}(c, l_1)\}$  $\mathrm{Eff}^+: \{\mathrm{At}(c, l_2)\}$ [cite: 10] |
|  | 所持 (Possession) | $\mathrm{Has}(c, o)$  $\mathrm{AtObject}(o, l)$ | $a = \mathrm{Take}(c, o, l)$  $\mathrm{At}(c, l) \land \mathrm{AtObject}(o, l)$ | $\mathrm{Eff}^-: \{\mathrm{AtObject}(o, l)\}$  $\mathrm{Eff}^+: \{\mathrm{Has}(c, o)\}$ [cite: 10] |
|  | 生死・健康 (Vitality) | $\mathrm{Alive}(c)$  $\mathrm{Injured}(c)$ | $a = \mathrm{Attack}(c_1, c_2)$  $\mathrm{Alive}(c_1) \land \mathrm{Alive}(c_2) \land \mathrm{SameLoc}(c_1, c_2)$ | $\mathrm{Eff}^-: \{\mathrm{Alive}(c_2)\}$  $\mathrm{Eff}^+: \{\mathrm{Dead}(c_2)\}$ [cite: 10] |

|  | 同盟・敵対 (Alliance) | $\mathrm{Allied}(c_1, c_2)$  $\mathrm{Hostile}(c_1, c_2)$ | $a = \mathrm{Betray}(c_1, c_2)$  $\mathrm{Allied}(c_1, c_2)$ | $\mathrm{Eff}^-: \{\mathrm{Allied}(c_1, c_2)\}$  $\mathrm{Eff}^+: \{\mathrm{Hostile}(c_1, c_2)\}$ [cite: 10] |

#### 2.3 記号AIとニューラルNLPのハイブリッド構造
記号プランナー（PDDLやAnswer Set Programming: ASP）は、厳密な因果整合性を保証できるものの、自然言語の豊かな表現力や暗黙の文脈適応力に欠ける。一方でLLMは流暢なテキストを生成・解釈できるが、長期的な事前条件の違反や状態忘却を頻発させる。このトレードオフを解消するため、両者を結合するハイブリッドアプローチが確立されつつある。
代表例として、ASPや古典的ナラティブプランナー（例: Glaive）を用いてキャラクターの「意図性（Intentionality）」や「対立関係（Conflict）」を満たすアクション連鎖を記号空間で探索・生成し、その各ステップをLLMが自然言語へと表面化（Surface Realization）する手法が挙げられる。また、強化学習やプランニング実行系において、ベイジアンネットワーク（Bayesian Network）や論理規則を「記号的検証器（Symbolic Verifier）」あるいは「記号的執行器（Symbolic Enforcer）」として配置し、LLMが提案したアクションの事前条件成立を外部から監視・介入する機構も提案されている。SHOWRUNNERシステムのように、自然言語によるストーリー入力をゲームエンジン内部のデータ辞書および事前条件・効果メソッドと結びつけ、3D仮想空間で矛盾なくシミュレーション実行・可視化する統合実装も進展している。
### 3. 重要アクション文の識別と背景・心理描写のフィルタリング技術
自由記述の物語テキストには、プロットを物理的・社会的に前進させる「中核的イベント（Kernels）」と、情景描写、登場人物の感情・内面心理、過去の回想といった「装飾的要素（Catalysts / Satellites）」が混在している。状態追跡の破綻を防ぐためには、テキストから状態変化を引き起こす重要アクション文のみを高精度に識別し、背景ノイズから切り分けるフィルタリング機構が不可欠である。
#### 3.1 アスペクト論および談話構造理論による言語学的峻別
計算言語学的には、事象アスペクト論（Vendler's Aktionsart）および談話構造理論（SDRT / RST）が弁別の基礎理論を提供する。
動詞のアスペクト特性において、状態動詞（State: 「悲しんでいた」「静かだった」）は時間的限界を持たず状態差分を生じさせない（$\Delta S = \emptyset$）。活動動詞（Activity: 「歩き回った」「空を見つめた」）は持続的な動作を表すが、明確な完了点（Telic endpoint）を欠き、本質的な状態変化を伴わないことが多い。これに対し、到達動詞（Achievement: 「見失った」「着いた」）や達成動詞（Accomplishment: 「城を攻略した」「鍵を開けた」）は明確な限界点を有し、不可逆な物理的・社会的状態変化（$\Delta S \neq \emptyset$）を引き起こす。したがって、述語のアスペクト解析および完了性の判定が、状態変化イベント抽出の一次フィルタとして機能する。
談話構造論（Segmented Discourse Representation Theory: SDRT）の観点では、文や節の間に成立する談話関係ラベルが弁別の基準となる。先行事象から時間軸を前進させて結果を導く関係（Narration, Result）は状態変化を担う主幹プロットを構成するのに対し、時間経過を伴わずに状況を補足する関係（Background, Elaboration, Comment）は描写情報に属する。談話依存構造解析を用いて後者のエッジで結ばれた節や文を枝刈り（Pruning）することにより、物語の因果関係骨格（Causal Backbone）を純粋に抽出することが可能となる。
#### 3.2 フィルタリングと抽出の多段階パイプライン
実用的な情報抽出システムでは、自由記述テキストから状態変化タプルを導出するために、単一のエンドツーエンドモデルに依存せず、段階的な構造化プロセスが採用される。
最初期の談話前処理段階では、テキスト中の代名詞や省略された言及を共参照解決によって明示的な固有名詞・キャラクター識別子へと置換（Pronoun Substitution）し、さらに複文や重文を単一の主語・述語関係からなる単純節へと平坦化・分割（Clause Simplification）する。この処理により、1文の中に情景描写と重要アクションが同居している場合でも、両者を独立した命題単位として分離できる。
続くアクション性判別段階では、語彙・意味論的特徴に基づくスクリーニングが実行される。BookNLPに組み込まれているWordNetスーパセンス（Supersense）分類器を利用し、述語が verb.change（変化）、verb.motion（移動）、verb.possession（所持）、verb.contact（接触）に属するものを状態変化候補として選択し、verb.cognition（認識）、verb.emotion（感情）、verb.perception（知覚）に属する内面描写を分離・フィルタリングする。さらに、LitSeg（Narrative-Theory-Guided Segmentation）フレームワークにみられるように、物語論のプロット構造に基づいてノイズを排除し、転換点（Turning Points）となる主要イベントを多段階プロンプティングによって同定する手法が有効である。LitSeg-Liteのように、この多段階推論データを単一パスの軽量モデルへと蒸留することで、高い推論速度と抽出精度を両立させる実装も実用化されている。
最終的な構造化段階では、抽出されたアクション節から「主体（Agent）」「動作（Action）」「対象（Patient / Theme）」「起点・着点（Source / Goal）」の意味役割を同定し、事前定義されたオントロジーまたはLLMの構造化出力によって状態差分タプル $\langle c, \text{Property}, S_{pre}, S_{post} \rangle$ を生成して世界モデルへ書き込む。
### 4. 日本語テキストにおける固有課題とオープンソース解析エコシステム
日本語の物語・小説テキストからキャラクター状態とイベントを正確に抽出する際には、形態論、統語論、および語用論の各階層において英語圏の標準的パイプラインでは対応できない特有の言語的障壁が存在する。
#### 4.1 日本語物語テキスト特有の言語現象
日本語の小説テキストにおいて最も顕著な課題は、極度の主語および目的語の省略（ゼロ代名詞 / Zero-Anaphora）である。文脈上既知とされる動作主（ガ格）や対象（ヲ格・ニ格）は表層から頻繁に脱落する。例えば「部屋に入ると、すぐに引き出しを開けた。短銃を握りしめ、窓際へと身を寄せた。」という連続文において、すべての動詞（入る、開ける、握りしめる、寄せる）の主語が省略されている。これらを正確に追跡するには、単文内の依存関係だけでなく、先行文脈全体から省略された項を同定する述語項構造解析（Predicate-Argument Structure: PAS Analysis）が不可欠である。
さらに、受動（「〜れる／られる」）、使役（「〜せる／させる」）、および授受表現（「〜てやる／てくれる／てもらう」）の多用が、意味役割の割り当てを複雑化させる。特に被害受動（迷惑受動: 「敵に退路を断たれた」）や授受補助動詞は、表層の文法上の格と深層の意味役割（動作主・被影響者）を逆転させるだけでなく、語り手や視点人物の感情的・視点的一致度（Empathy / Perspective）を暗黙に指示する。したがって、これらの接辞や補助動詞を解析しなければ、所有権の移動方向や被害・加害の力学ベクトルを誤認することになる。
また、日本語小説では「役割語（Role Language）」や敬語体系（尊敬語・謙譲語・丁寧語）が高度に発達している。会話文において話者の名前が明記されない場合でも、一人称代名詞（「妾（わらわ）」「俺」「小生」）や特有の文末詞（「〜じゃ」「〜であります」）から話者の属性が直接同定可能である。同時に、対話者間で交わされる敬語の有無や方向性は、明示的な説明記述なしに登場人物間の社会的権力関係や上下関係の力学を確定させる重要な情報源となる。

#### 4.3 日本語環境における実践的ハイブリッド処理系
日本語小説から動的なキャラクター状態追跡を行うための実践的なパイプラインは、長編全体のエンティティ管理に長けたBookNLPの設計思想と、文脈深層解析に長けたKWJAの推論能力を結合させる構成が最も現実的かつ高精度である。
処理の第一段階として、鉤括弧（「」）を境界マーカーとして利用し、会話文と地の文の分離を行う。地の文についてはKWJAを実行し、係り受け解析と同時に述語項構造解析（PAS）を適用する。各文の述語に対して省略されているガ格（動作主）、ヲ格（対象）、ニ格（相手・場所）の参照先を文脈トークン列から選択させ、表層で欠落している格要素を明示的に復元する。会話文に付随する発話者同定においては、直前・直後の地の文にある発話動詞（「言った」「呟いた」等）のガ格解析結果を直接リンクさせるとともに、明示的記述がない箇所では発話文内の役割語や丁寧度を照合して直前の発話話者クラスタと紐付ける。
第二段階として、ゼロ照応が解消されて主語・対象が補完されたアクション文に対し、受動・使役・授受の補助動詞判定ルールを適用して意味役割の反転や正規化を行う。これにより、「AがBに倒された」という受動文は「BがAを攻撃し、Aが敗北した」という能動的な状態遷移命題へと統一される。
最終段階として、正規化されたアクション命題から変化述語を抽出し、事前条件の確認と事後効果の更新を行う。KWJAの共参照解析モジュールによって同一人物の別称（例: 「青年」「彼」「佐藤」）が一単一のエンティティIDへ統合されているため、抽出された状態差分（$\mathrm{Eff}^+, \mathrm{Eff}^-$）は各エンティティの動的プロファイルテーブルへ正確に反映され、談話全体を通じた矛盾のない状態追跡が達成される。
### 5. 統合分析と将来の展望
物語テキストにおける動的状態追跡とイベント抽出の研究は、局所的な文法処理や単一文の分類タスクを脱し、記号的世界表現と基底言語モデルが相互作用する「計算ナラトロジー（Computational Narratology）」の総合的システムへと発展した。
現在の技術体系における中心的な理論的対立は、局所的な構文・意味解析（マイクロレベル）と大局的な物語一貫性の管理（マクロレベル）の間に存在する。KWJAをはじめとする最新の統合言語解析器は、文レベルや短い段落内における主語省略や照応関係の同定において極めて高い精度を実証している。しかしながら、長編小説全体にわたる長距離のプロット進行においては、登場人物の生死やアライアンスの変化、隠蔽された事実の暴露といったマクロな状態遷移が複雑に累積し、最先端のLLMを用いても一貫性の崩壊（ConStory-Benchで示されるような記憶の矛盾や能力の喪失）を完全に防止することは困難である。これは、文学テキストが持つ「意図的な情報の遅延提示（サスペンスや伏線）」「主観的視点による事実の歪曲（信頼できない語り手）」「反事実的な仮定描写」が、古典的プランニングが前提とする完全情報・単調増加的な論理体系と本質的に乖離していることに起因する。
今後の研究展開において有望視されるアプローチは、第1に、論理的プランニング系と生成系モデルを密結合させたニューロ・シンボリック実行機構の高度化である。ベイジアンネットワークやPDDLソルバーを推論エンジン（Symbolic Verifier）として常駐させ、LLMがイベントを抽出または生成する都度、事前条件の充足度を数学的に検証してハルシネーションや状態矛盾を剪定する機構の一般化が期待される。第2に、高コンテクスト言語における語用論的制約の数理モデル化である。特に日本語において顕著な敬語体系や役割語、授受動詞が担う視点・権力勾配を定式化し、物理的状態のみならず「社会的・心理的力学（Social Dynamics）」の遷移関数として世界モデルに組み込むことが、高度な物語理解と自律的エージェントシミュレーションの実現に向けた決定的な鍵となる。
